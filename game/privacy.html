Privacy & storage

MiniZap · Kartoffelkanone · updated 3 October 2026

The operator and data controller is Peter Schulz, Frommannstr. 14, 90419 Nürnberg, Germany. Privacy contact: minizap@les.bar.

Local game data

Progress, your chosen name, equipment, records, statistics, appearance and preferences are saved in your browser's local storage, together with language choice, an installation-hint marker and pending record uploads. Data is specific to this browser and website address and remains until you clear site data or your browser removes it. Blocking storage leaves session-only play where supported.

The game uses no advertising or analytics cookies. Fonts and artwork are served by this website, without Google Fonts requests, social embeds or a service worker.

Online records and shared flights

New personal ground records with traffic enabled are automatically submitted to api.minizap.online. Pending uploads and compatible prior local records can also be submitted on a later visit. Submissions contain the chosen display name and replay inputs, including seed, equipment, appearance, actions and results. The server verifies distance and stores creation time; listed records show name, distance and timestamp publicly.

Sharing may create a short replay link by uploading an unlisted flight. Unlisted flights are retrievable by ID and are not confidential. Self-contained fallback links carry replay data in the URL fragment. Use a nickname without your real name or contact information; you do not need an account.

The database currently has no automatic age-based deletion. Request removal using the contact below. Daily server snapshots retain seven dated backups; database retention and backup retention are different. Clearing browser data removes pending uploads and your local save, but does not delete existing server records or copies already shared by others.

Hosting and technical requests

GitHub Pages hosts the game; the separate MiniZap API runs on VPS infrastructure. Hosts receive ordinary HTTP request information, including IP address, requested URL, time and browser headers. The API's flight database has no IP column. Its transient IP rate-limit entries use a one-minute window and are removed on subsequent requests after expiry. This does not describe hosting/proxy log retention.

The global list is fetched about every ten seconds while the tab is visible, with failure backoff. Release checks occur no more often than every five minutes; updates are offered manually. GitHub describes its technical data handling, retention criteria and international transfers in its privacy statement. Hosting enables delivery and abuse protection; public flight storage enables replay retrieval and ranking.

Contact, removal and your rights

Email minizap@les.bar for access, correction, deletion, restriction, portability where applicable, or an objection to processing. Include a flight link if available; without accounts we may need proportionate information to identify the data concerned. You may complain to the competent data protection authority. Clearing local site data stops remaining local queued submissions, but is destructive to local progress. Do not assume renaming your pilot changes old published names.

External links and support

Twitch, Telegram and GitHub links are ordinary navigation links, with no embedded widgets. Their policies apply when you visit them. Email uses your mail application. The optional Solana support link opens a wallet if supported; the game does not connect to a wallet or track donations. Blockchain transactions are public and cannot be erased like a browser save. Support grants no game benefit.

Lokale Daten

Fortschritt, Name, Talente, Rekorde, Statistik, Aussehen und Einstellungen bleiben im lokalen Browserspeicher. Hinzu kommen Sprache, Installationshinweis und ausstehende Rekordübertragungen. Daten gehören zu diesem Browser und dieser Webadresse und bleiben bis zum Löschen der Website-Daten oder einer Entfernung durch den Browser. Es gibt keine Werbe-/Analyse-Cookies, externen Schriftabrufe oder eingebetteten Social-Media-Widgets.

Online-Flüge

Neue persönliche Bodenrekorde mit Gegenverkehr werden automatisch an api.minizap.online übertragen. Gespeicherte ausstehende Übertragungen und passende frühere lokale Rekorde können bei späteren Besuchen folgen. Übertragen werden dein gewählter Name sowie Flugdaten für die Wiederholung (Startwerte, Talente, Aussehen, Aktionen und Ergebnis). Die öffentliche Liste zeigt Namen, geprüfte Weite und Zeitpunkt. Nutze einen Spitznamen ohne persönliche Kontaktdaten.

Teilen kann einen nicht gelisteten Flug für einen Kurzlink speichern. Er ist über seine ID abrufbar und nicht vertraulich. Ersatzlinks enthalten Flugdaten im URL-Fragment. Es gibt keine automatische altersabhängige Löschung der Datenbank; Löschung kannst du per E-Mail anfragen. Tägliche Backups behalten sieben datierte Sicherungen. Browserdaten zu löschen entfernt Spielstand und ausstehende Übertragungen, aber keine bereits gespeicherten oder von anderen kopierten Flüge.

Hosting

GitHub Pages liefert die Website aus, die separate API läuft auf einem VPS. Hosts erhalten technische Anfragedaten wie IP-Adresse, URL, Zeit und Browser-Header. Die Flug-Datenbank speichert keine IP-Adresse. Die API verwendet kurzlebige IP-Einträge zur Begrenzung von Anfragen mit einem einminütigen Fenster; abgelaufene Einträge werden bei nachfolgenden Anfragen entfernt. Das beschreibt nicht die Aufbewahrung von Hosting-/Proxy-Logs. Die globale Liste wird im sichtbaren Tab etwa alle zehn Sekunden abgerufen, Updates frühestens alle fünf Minuten. Weitere Angaben zu GitHub stehen in dessen Datenschutzerklärung.

Kontakt und Rechte

Für Auskunft, Berichtigung, Löschung, Einschränkung, gegebenenfalls Datenübertragbarkeit oder Widerspruch: minizap@les.bar. Gib möglichst den Fluglink an. Ein neuer Pilotenname ändert keine früher veröffentlichten Namen.

Externe Kontaktlinks öffnen erst beim Anklicken den jeweiligen Dienst. Dessen Datenschutzhinweise gelten dort. Der freiwillige Solana-Link verbindet das Spiel nicht mit einer Wallet. Blockchain-Transaktionen sind öffentlich und nicht wie Browserdaten löschbar; Unterstützung gibt keine Spielvorteile.
