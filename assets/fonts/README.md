# Local comic lettering

Unmodified TrueType assets from the Google Fonts repository, retrieved 2026-09-18:

- Bangers Regular: https://github.com/google/fonts/tree/main/ofl/bangers
- Comic Neue Regular and Bold: https://github.com/google/fonts/tree/main/ofl/comicneue

Copyright notices and SIL Open Font License 1.1 are included in the adjacent OFL files. No runtime requests to Google Fonts. Bangers handles titles and short action labels; Comic Neue handles readable body copy, controls and telemetry. The original archived game retains its own typography.
